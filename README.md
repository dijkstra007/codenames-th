# เกมสายลับภาษาไทย

เว็บเกมกระดานคำศัพท์ภาษาไทย เล่นบนหน้าจอเดียวกันกับเพื่อน ๆ ได้เลย (ไม่ต้อง login, ไม่มี backend)

**เล่นได้ที่** https://dijkstra007.github.io/codenames-th/

โปรเจกต์แฟนที่ไม่เป็นทางการ ไม่ได้เกี่ยวข้องกับ Czech Games Edition หรือเกม Codenames ฉบับจำหน่าย

## วิธีเล่น

กระดาน 5×5 สุ่มจากคลังคำนามไทย 458 คำ ทีมที่เริ่มมี 9 ใบ อีกทีมมี 8 ใบ ที่เหลือเป็นใบกลาง 7 ใบกับนักฆ่า 1 ใบ

**หน้าจอเดียว**

1. สายลับของทีมที่เริ่มกด **ดูกุญแจสายลับ** (หรือ `Esc` เพื่อซ่อน) แล้วใบ้คำ + จำนวนใบ
2. กรอกคำใบ้และจำนวนที่เหลือทายในแถบด้านบนได้ตามสะดวก
3. ผู้เล่นแตะการ์ดเพื่อเปิด — ถ้าเปิดกฎเข้มไว้ การ์ดผิดสีหรือใบกลางจะสลับเทิร์นให้อัตโนมัติ นักฆ่ายังแพ้ทันที
4. กด **เลิกทำ** ถ้าแตะผิด (ใช้ไม่ได้หลังจบเกม)

**สายลับบนอีกเครื่อง**

1. กด **แชร์ให้สายลับ** แล้วให้สายลับสแกนคิวอาร์ด้วยโทรศัพท์ (หรือส่งรหัส) เท่านั้น
2. สแกนแล้วจะเปิด [spymaster.html](spymaster.html) บนเครื่องนั้น — คิวอาร์คือกุญแจทั้งกระดาน ใครสแกนจะเห็นสีทุกใบ
3. สถานะการเปิดการ์ดไม่ได้ซิงก์ข้ามเครื่อง นี่เป็นสแนปชอตตอนแชร์

## Run locally

ไฟล์เป็น static — เสิร์ฟผ่าน HTTP เพราะใช้ ES modules

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

รันเทสต์ (Node, ไม่มี dependency):

```bash
node --test tests/*.test.js
```

## เทคโนโลยี

Vanilla HTML + CSS + JavaScript (ES modules) ไม่มี build step

ฟอนต์ Noto Sans Thai / Noto Serif Thai โหลดจาก Google Fonts ตอนออนไลน์ ถ้าโหลดไม่ได้จะใช้ `Sukhumvit Set` และฟอนต์ระบบตามที่กำหนดใน CSS
